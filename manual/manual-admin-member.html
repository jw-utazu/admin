1. メンバー一覧を確認する

手順

  2. 2メンバー一覧モーダルが開く

2. メンバーを追加する

手順

  1. 1メンバー一覧モーダル右下の「＋ メンバー追加」をタップ
  2. 2追加フォームが表示されるので各項目を入力
  3. 3「保存」ボタンをタップして登録完了
「名前（かな）」は五十音順の並び替えに使用します。正確に入力してください。

3. メンバー情報を編集する

手順

  1. 1メンバー一覧で対象メンバーの「編集」ボタンをタップ
  2. 2編集フォームが展開される
  3. 3変更したい項目を修正
  4. 4「保存」ボタンをタップ

4. メンバーを無効化・再有効化する

無効化の手順

  1. 1対象メンバーの「編集」をタップして編集フォームを開く
  2. 2「無効にする」ボタンをタップ
  3. 3確認ダイアログが表示されたら「OK」をタップ
  4. 4メンバーが薄く表示され、シフトフォームに表示されなくなる

再有効化の手順

  1. 1無効化されたメンバーの「編集」をタップ
  2. 2「有効にする」ボタンをタップ
メンバーを無効化しても、過去のシフトデータは保持されます。削除ではなく非表示状態です。
