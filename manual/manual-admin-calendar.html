1. カレンダーの見方

メイン画面左側のカレンダーに、日程情報が色分けで表示されます。

  • 緑チップ「申込開始」 — シフト希望の申込が開始される日
  • 赤チップ「締切」 — 申込の締め切り日
  • 青チップ「シフト公開」 — シフト表が公開される日
  • 紫チップ「スロット」 — 実施日（奉仕活動がある日）
  • オレンジバー（下部） — 申込受付期間中の日

2. 実施日の詳細確認

手順

  1. 1カレンダーで紫チップ（スロット）が表示されている日付をタップ
  2. 2カレンダー下に「実施日詳細」カードが展開される
  3. 3その日の時間帯スロット一覧が表示される
  4. 4閉じる場合は右上の「×」ボタンをタップ

3. 日程設定（申込開始・締切・公開日）

日程カードの見方

カレンダー下の「日程一覧」カードに3つの日程が表示されます。

申込開始 — 希望申込を受け付け開始する日
締切日 — 申込を締め切る日
シフト公開 — シフト表を公開する日

日程を変更する手順

  1. 1日程カード内の変更したい項目（申込開始 / 締切日 / シフト公開）をタップ
  2. 2カレンダーが「編集モード」に切り替わる
  3. 3カレンダー上で新しい日付をタップして選択
  4. 4「保存」ボタンをタップして確定
  5. 5「🗑 一括リセット」で3つの日程をすべて削除できる
日程を設定しないと「募集開始処理」が正しく動作しません。毎月必ず設定してください。

4. 実施日設定（時間帯スロット）

手順

  1. 1カレンダー上で実施日（奉仕活動がある日）をタップ
  2. 2インラインポップアップで時間帯を設定する
  3. 3「＋ 時間帯を追加」でスロットを追加できる
  4. 4開始・終了時刻と間隔（分）を選択
  5. 5「保存」ボタンをタップ
  6. 6「🗑 一括リセット」で全実施日スロットを削除できる
間隔はシフト表の時間刻み（5分・10分・15分・20分・30分）です。奉仕の種類に合わせて選んでください。
