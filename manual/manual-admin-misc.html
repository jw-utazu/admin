1. お知らせ管理

奉仕者アプリに表示される「お知らせ」を作成・編集・削除できます。

お知らせを追加する

  1. 1サイドバーの「📢 お知らせ管理」をタップ
  2. 2「＋ 追加」ボタンをタップ
  3. 3タイトルと本文を入力
  4. 4「保存」をタップ

お知らせを編集・削除する

  1. 1お知らせ一覧から対象のカードを探す
  2. 2「編集」ボタンで内容を変更 / 「削除」ボタンで削除

2. 要望確認

奉仕者アプリから送られた機能改善要望を確認・管理できます。

手順

  1. 1サイドバーの「💬 要望確認」をタップ
  2. 2要望一覧が表示される
  3. 3対応済みの要望は「対応済みにする」をタップしてステータスを更新
未対応の要望は黄色バッジ、対応済みは緑バッジで表示されます。

3. バグ報告確認

奉仕者アプリから送られたバグ報告を確認できます。操作方法は「要望確認」と同じです。

手順

  1. 1サイドバーの「🐛 バグ報告確認」をタップ
  2. 2バグ報告一覧が表示される
  3. 3内容を確認し、対応済みになったら「対応済みにする」をタップ

4. 展示内容写真管理

カート奉仕で使用する展示内容（書籍・雑誌など）の写真をアップロード・管理します。奉仕者アプリの「カート表示」として公開されます。

写真をアップロードする

  1. 1サイドバーの「🖼 展示内容写真管理」をタップ
  2. 2モーダル右下の「📤 写真を追加」ボタンをタップ
  3. 3ファイル選択ダイアログが開くので、写真ファイルを選択（複数可）
  4. 4アップロードが完了すると写真一覧に表示される

写真を削除する

  1. 1写真一覧で削除したい写真をタップ
  2. 2「削除」ボタンをタップ
JPEG・PNG形式の画像に対応しています。複数枚を一度に選択してアップロードできます。

5. 代理送信設定

特定のメンバーの代わりにシフト希望を送信できるユーザーを設定します。スマートフォンを持っていないメンバーの希望を代理入力する場合に使用します。

代理送信者を追加する

  1. 1サイドバーの「🔄 代理送信設定」をタップ
  2. 2「追加」ボタンをタップ
  3. 3代理送信する 送信者（代理を行う人） と 対象者（希望を送られる人） を選択
  4. 4「保存」をタップ

代理送信者を削除する

  1. 1設定一覧から削除したい行の「削除」をタップ
