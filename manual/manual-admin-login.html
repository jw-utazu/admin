1. ログイン方法

手順

  1. 1ブラウザで PW管理アプリ のURLを開く
  2. 2ログイン画面が表示されたら「Googleでログイン」ボタンをタップ
  3. 3管理者として登録されたGoogleアカウントを選択する
  4. 4読み込み後、メイン画面が表示される
2回目以降は自動ログインされるため、ボタンをタップする必要はありません。
管理者として登録されていないアカウントではログインできません。

4. ログアウト方法

手順

  1. 1ヘッダー右上の「ログアウト」ボタンをタップ
  2. 2ログイン画面に戻る
次回アクセス時は自動ログインが試みられます。完全にログアウト状態を保ちたい場合はブラウザのキャッシュをクリアしてください。
